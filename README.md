# 录音笔高阶用法 · 安装说明

18 种把录音交给大模型干活的高阶用法。支持 Claude Code、Codex、WorkBuddy、千问、豆包；支持讯飞录音笔、讯飞听见、Deepting 三个录音 App。

## 一句话安装（推荐）

在你要使用的那个 AI 助手里，发这句话：

```
请帮我安装「录音笔高阶用法」并按提示完成设置：curl -fsSL https://liyubuke.github.io/tianjie/install.sh | bash
```

AI 会依次完成：

1. 把技能装进当前这个 AI 工具（只装这一个，不碰你电脑上的其他 AI 工具）；
2. 问你用哪个录音 App：讯飞录音笔 App、讯飞听见 App、Deepting App，可以多选；
3. 装好对应的读录音组件，打开网页让你登录账号、完成授权，检查通过为止；
4. 让你点选一种用法，确认后开始。

自己在终端装也可以，装完再打开 AI 助手说「录音笔高阶用法」，会接着做第 2～4 步：

- Mac / Linux：`curl -fsSL https://liyubuke.github.io/tianjie/install.sh | bash`（会让你选装到哪个 AI 工具）
- Windows（PowerShell）：`irm https://liyubuke.github.io/tianjie/install.ps1 | iex`

## 三个录音 App 对应的组件

| 录音 App | 组件 | 单独安装指令 |
|---|---|---|
| 讯飞录音笔 App（智声互联） | recording-assistant-prod | `curl -fsSL https://liyubuke.github.io/tianjie/install.sh \| bash` |
| 讯飞听见 App | xftj-transcribe | `curl -fsSL https://skillhub.cn/install/install.sh \| bash && skillhub install xftj-transcribe` |
| Deepting App | deepting-transcribe | `curl -fsSL https://skillhub.cn/install/install.sh \| bash && skillhub install deepting-transcribe` |

一般不用手动装：用法第一次启动时会按你选的 App 自动装、自动引导登录授权。以后想加一个 App，对 AI 说「加一个录音 App」就行。

## 开始：不用记名字，直接说要做的事

| 什么时候 | 直接对 AI 说 |
|---|---|
| 刚开完会 | 「整理刚才那场会」 |
| 周五下班前 | 「用这周的录音写周报」 |
| 见人、开会前 | 「明天见××，帮我回顾以前聊过的」 |
| 汇报前 | 「领导看这份材料会问什么」 |
| 想看全部用法 | 「录音笔高阶用法」或「用法菜单」（Claude Code 里输入 / 再打「录音」也能找到） |

- 说「用法菜单」会先列出入门、进阶、高阶、专家四级共 18 种用法，点选级别、点选用法，再点「确认开始」。全程点选，基本不用打字；
- 做完可以接着提修改意见，或者说「菜单」换一种；
- 第一次设置时，AI 会问要不要「记住你装了它」：同意后，你只说「整理刚才的会」这类话，它也会主动用这个技能。

## 让它更懂你（推荐，3 分钟）

发一两份你以前的东西，以后的产出就照你自己的格式、口径和习惯来写：

- **写作样板**：以前的周报、汇报材料、发过的邮件、满意的纪要；
- **人与组织**：通讯录、常汇报的领导和他关心什么；
- **业务口径**：产品清单、术语表、目标口径说明；
- **改前改后**：领导改过的稿子，最管用。

对 AI 说「让它更懂我」，把文件拖进对话就行。它会先列出「从你的资料里学到了什么」让你确认，再记下来；你平时改稿时说的习惯（比如「再短一点」「数字放前面」），它也会问你要不要记住。说「看看你记了我什么」随时查看、修改或删除。资料只存在你自己电脑上。

## 说明

- 本技能只读你的录音，不会上传、修改或删除录音，不会替你发消息；
- 会在你的主目录下建一个「录音笔高阶用法」文件夹，存录音来源、你的画像和资料、知识库等，写入前会告诉你；
- Deepting 重新授权会让旧的 API Key 失效，所以只有授权失效时才会重新授权；
- 没装组件也能用：直接粘贴转写文本或上传转写文件。
- 每天第一次使用会自动检查更新，有新版本会提醒你，同意后自动更新；你的设置、画像、资料和知识库不受影响。
